# Артефакты публичного контура

Здесь лежат ресёрчи, аудиты и отчёты, которые **можно публиковать**: они прошли чекер
границ и не содержат внутренних данных. Всё остальное живёт в закрытом контуре.

Правила — `governance/DOCS.md` §4. Шаблон — `governance/templates/ARTIFACT.md`.

## Зачем папка, если почти всё уходит в закрытый контур

Чтобы у публичных выводов было место, откуда на них можно сослаться. Отчёт «почему
на сайте нет сравнения с вендорами» или «что показал технический аудит сайта» — публичный
артефакт: он объясняет решение и не раскрывает внутреннего. Такой отчёт не должен лежать
в переписке или на диске.

## Как завести

```bash
python3 tools/docs-registry.py --new audit "аудит-навигации"
```

Создастся `artifacts/audit/ГГГГ-ММ-ДД-аудит-навигации.md` с шапкой. Дальше:

1. Заполнить разделы (вопрос, что проверено, выводы, что делать).
2. Проверить границы:

   ```bash
   python3 tools/check-boundaries.py artifacts --profile public
   ```

3. Если чекер ругается — артефакт не переписывается «до прохождения», а переносится
   в закрытый контур.
4. Пересобрать индекс: `python3 tools/docs-registry.py --index`.
5. Закоммитить файл и индекс вместе.

## Именование

`ГГГГ-ММ-ДД-короткое-имя.md` — дата работы, латиница или кириллица через дефис, без пробелов.
Дата в имени = дата работы, а не дата коммита: по ней считается старение.

## Что здесь не живёт

| Нельзя | Куда |
|---|---|
| цены, тарифы, условия поставщиков, расчёты выгоды | закрытый контур |
| имена и отрасли заказчиков | закрытый контур |
| внутренние ссылки и имена файлов закрытого контура | закрытый контур |
| черновики без шапки | сначала `draft` в шапке, потом коммит |

## Устаревание

Артефакт не удаляется. Он переводится в устаревшие с указанием замены:

```bash
python3 tools/docs-registry.py --deprecate artifacts/audit/2026-11-02-аудит-навигации.md \
    --by artifacts/audit/2027-02-01-аудит-навигации-v2.md
```

Команда ставит `status: superseded`, добавляет `superseded_by` и видимый баннер.
