# T2c — решающий тест движка: подмена chat-шаблона (гипотеза парафразов)

Дата: 2026-11-01, стенд B (IT-AI-Test2, 10.10.0.98). Модель qwen3:4b-instruct (GGUF из ollama-блоба),
llama.cpp 0.8.0-dev (локальная CUDA-сборка из T2, `/root/ft_tests/t2/build/bin`).

База: protocols/T2b.md (коммит 0766623). Конфигурация-победитель T2b: llama-server `-np 4`,
ctx 8192×4, `-fa on`, `-ctk/-ctv q8_0`, temp 0 → 318 зв/ч, quote-miss ~1,5 % (94 промаха,
из них 84 — парафраз цитат).

## Гипотеза

Парафразы цитат — побочный эффект чат-шаблона llama.cpp (шаблон, зашитый в GGUF),
а не свойство GGUF/модели. Фикс: подать оригинальный шаблон из HF-токенайзера
Qwen/Qwen3-4B-Instruct-2507 через `--chat-template-file`.

## Что сделано

1. Из `tokenizer_config.json` Qwen/Qwen3-4B-Instruct-2507 (HF) извлечён `chat_template`
   (2630 байт) → `/root/ft_tests/t2c/qwen3_chat_template.jinja`.
2. Из GGUF выгружен встроенный `tokenizer.chat_template` (4040 байт). **Шаблоны различаются:**
   - GGUF несёт **thinking-гибридный** шаблон Qwen3: namespace `multi_step_tool`,
     вырезание `reasoning_content` из истории, и главное — подстановка пустого блока
     `<think>\n\n</think>\n\n` в промпт генерации;
   - HF-шаблон Instruct-2507 — **нон-тинкинг**: без think-логики, генерация стартует сразу.
   Полный diff: `/root/ft_tests/t2c/template.diff` на стенде.
3. Способ (1) `--chat-template-file` — **сработал с первого раза** (способы 2–3 не понадобились).
   Верификация подмены: одна и та же 4-репленная переписка с `<think>abc</think>` в истории
   даёт разный рендер: prompt_tokens 30 (GGUF-шаблон, think-блок вырезан из истории,
   к генерации добавлен пустой `<think>`) против 33 (HF-шаблон, история без изменений,
   генерация без think-преамбулы).
4. Прогон по методике T2b: 116 звонков/страты, format-схема с `required:["items"]`,
   каскадный парсер (strict → regex → salvage), 4 воркера, temp 0, evidence_maxlen 120.

## Вердикт

**СДАНА НЕТ: quote-miss 1,52 % > 1 %.** Остальные критерии выполнены с запасом.

Пропускная способность и надёжность не изменились относительно T2b (318→324 зв/ч,
schema-fail 0, VRAM 5175). quote-miss 1,52 % против 1,82 % (финальный артефакт T2b на
стенде; в протоколе 0766623 зафиксировано 1,5 %/94) — разница на уровне шума одиночного
прогона, парность конфигураций по смыслу не меняется.

**Шаблон исключён.** Подмена thinking-шаблона GGUF на оригинальный нон-тинкинг-шаблон HF
не убрала парафразы (84+ → 95 промахов; структура промахов — те же парафразы цитат).
Следовательно, парафразы — свойство GGUF/модели (квантование оригинального блоба ollama),
а не чат-шаблона llama.cpp.

## Следствие для решения владельца

Дальнейшие попытки починить llama.cpp-контур настройкой шаблона бесперспективны.
Выбор между двумя подтверждёнными конфигурациями:

- **T1b**: 105–115 зв/ч, quote-miss 0,56 % — качество цитирования, скорость ниже порога 200;
- **T2b/T2c**: 318–324 зв/ч, quote-miss ~1,5–1,8 % — скорость с запасом, качество цитирования
  выше порога 1 %.

Единственный неявный резерв — другой GGUF-квант той же модели (свойство GGUF не проверялось
на иных квантах); это отдельный тест и отдельное решение.
