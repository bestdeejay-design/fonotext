# Fonotext — речевая аналитика телефонных разговоров

**Транскрибация, классификация и дашборды для колл-центров, отделов продаж и сервиса.**

Платформа превращает записи звонков (стерео: клиент/оператор) в структурированные данные:
полный транскрипт с таймкодами, автоматическая классификация каждого звонка (автоответчик,
спам-блокировка, робот, результат разговора, соблюдение скрипта) и готовые дашборды для
руководства — с задержкой **минуты, а не сутки**.

| | Ручная обработка | Fonotext |
|---|---|---|
| Покрытие звонков | 1–7 % (выборка) | **100 %** |
| Задержка отчётов | дни–недели | минуты |
| Исторический архив | практически недостижим вручную | обрабатывается партиями любого объёма |
| Стоимость минуты | ~11–23 ₽ (ФОТ со всеми накладными) | **от 1,2 ₽** (от 0,6 ₽ на объёмах) |
| Персональные данные | на слух у сотрудников | шифрование, RBAC, аудит, 152-ФЗ |

## Возможности

- **Транскрибация** русского языка с таймкодами на уровне слов; спикеры определяются
  физически по каналам записи — без нейросетевой диаризации и её ошибок.
- **Классификация каждого звонка**: тип соединения (живой разговор / автоответчик /
  спам-блокировщик / робот / без ответа), результат, теги, соблюдение скрипта оператором
  (обязательные и запрещённые фразы), конфликтность — таксономия настраивается под бизнес.
- **Метрики разговора**: talk ratio, перебивания, паузы, длительность.
- **Аналитика**: дашборды (ClickHouse + Apache Superset), карточка звонка (плеер +
  транскрипт с подсветкой каналов + теги), экспорт отчётов, вебхуки.
- **API**: загрузка звонков и получение результатов программно — спецификация:
  [docs/08-api.md](docs/08-api.md).
- **Развёртывание**: наше облако (РФ) или on-prem в контуре заказчика — одна кодовая база.

Подробности: [docs/02-architecture.md](docs/02-architecture.md), [docs/03-models.md](docs/03-models.md).

## Цены

Принцип: **расшифровки — по API за минуты по рыночным ценам; аналитика и «плюшки» — по
подписке.** Новым клиентам: 300 минут бесплатно и **−50 % на всё в первые 2 месяца**.
Детали — [docs/06-pricing.md](docs/06-pricing.md):

| Что | Что получаете | Цена |
|---|---|---|
| **API-транскрибация** (без подписки) | транскрипт, спикеры, таймкоды слов, метрики, вебхуки | 1,2 ₽/мин; от 0,6 ₽ на объёме; архив −65 % |
| **Подписка «Аналитика»** | классификация звонков, дашборды, скрипты операторов, поиск, карточка звонка | от 19 900 ₽/мес |
| **Коробка on-prem** | всё в контуре заказчика, минуты не тарифицируются | лицензия от 1,9 млн ₽ |
| **Проект «под ключ»** | разовый разбор накопленного архива | фикс-прайс от ~0,3 ₽/мин |

Требования к инфраструктуре и процесс внедрения: [docs/07-deployment.md](docs/07-deployment.md).

## Как мы работаем с новым заказчиком

1. **Анкета интеграции** ([docs/01-integration.md](docs/01-integration.md)) — 20 минут на
   заполнение: как хранятся записи, форматы, объёмы.
2. **Тест-режим сразу:** API-ключ, 300 минут бесплатно, −50 % на первые 2 месяца. Для
   аналитики по подписке — пилот 2–4 недели: качество распознавания и классификации измеряем
   на записях заказчика, согласуем таксономию и первые дашборды, фиксируем цифры в отчёте.
   Мы не обещаем «волшебный WER» — мы его измеряем и подписываемся цифрами.
3. **Поставка за 4–8 недель:** облако или коробка в контуре заказчика.
