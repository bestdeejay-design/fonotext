# Fonotext — речевая аналитика телефонных разговоров

**Разбор 100 % звонков: транскрипты со спикерами, классификация каждого разговора,
контроль скриптов с доказательствами и дашборды для руководства.**

🌐 Лендинг: **https://bestdeejay-design.github.io/fonotext/** ·
📊 Демо-стенд: [local-poc](local-poc/README.md) · 📄 Презентация: [docs/00](docs/00-product-presentation.md)

Платформа превращает записи звонков (стерео: клиент/оператор в разных каналах) в
структурированные данные: транскрипт с таймкодами на уровне слов, автоматическая классификация
каждого звонка (живой разговор, автоответчик, спам-блокировка, робот, без ответа; результат,
теги, соблюдение скрипта), метрики разговора и готовые дашборды — с задержкой **минуты, а не сутки**.

| | Как обычно | Fonotext |
|---|---|---|
| Покрытие звонков | 3 % (выборка ОКК) | **100 %**, включая «неудобные» |
| Задержка отчётов | дни–недели | минуты (SLA ≤ 24 ч) |
| Исторический архив | не разбирается никогда | партиями: 450 тыс. часов ≈ 6–12 недель |
| Спор «я это говорил» | переслушивание записи | цитата + таймкод + канал спикера |
| Смена таксономии | повторный прогон и бюджет | переклассификация **без** повторного распознавания |
| Цена «всё включено» | 3,8–5,5 ₽/мин у SaaS-класса | **1,19–2,49 ₽/мин** в подписке |
| Персональные данные | на слух у сотрудников | шифрование, RBAC, аудит, 152-ФЗ, приватный контур |

## Возможности

- **Транскрибация** русского языка с таймкодами на уровне слов; спикеры определяются
  физически по каналам записи — без нейросетевой диаризации и её ошибок.
- **Классификация каждого звонка:** тип соединения, результат, теги, соблюдение скрипта,
  конфликтность. Каскад «правила → LLM → человек»; низкая уверенность уходит в очередь
  ручного контроля. Таксономия настраивается без релиза — см.
  [10-feature-specs/02](docs/10-feature-specs/02-taxonomy-builder.md).
- **Доказательная база:** каждое нарушение скрипта — цитата, таймкод, канал; оператор может
  оспорить, спорный звонок уходит в разбор ([10-feature-specs/03](docs/10-feature-specs/03-script-evidence.md)).
- **Переклассификация без повторного ASR:** смена таксономии пересчитывает вердикты по
  сохранённым транскриптам — часы и копейки вместо повторного прогона
  ([10-feature-specs/01](docs/10-feature-specs/01-full-coverage.md)).
- **Разбор архива «под ключ»:** фикс-прайс от 0,38 ₽/мин, дашборд прогресса и ETA, итоговый
  аналитический отчёт ([10-feature-specs/04](docs/10-feature-specs/04-archive.md)).
- **Аналитика:** дашборды (ClickHouse + Apache Superset), карточка звонка (плеер + транскрипт
  с подсветкой каналов + теги), поиск, экспорт отчётов, вебхуки.
- **API:** загрузка звонков и получение результатов программно — [docs/08-api.md](docs/08-api.md).
- **Поставка:** облако (РФ), приватный контур на нашей аренде или on-prem — одна кодовая база
  ([07-deployment.md](docs/07-deployment.md), [10-feature-specs/05](docs/10-feature-specs/05-private-shard.md)).

## Почему это дешевле при том же качестве

Мы **не покупаем железо**: базовая мощность под SLA живёт на арендованных GPU, пики закрывает
автоскейл, архивы и бэклог считаются на прерываемых инстансах (скидка 40–75 %). Экономия на
амортизации уходит в цену, а не в маржу. Расчёт мощностей и стоимость обработки —
[docs/04-hardware.md](docs/04-hardware.md).

## Как мы работаем с новым заказчиком

1. **Анкета интеграции** ([docs/01-integration.md](docs/01-integration.md)) — 20 минут: как
   хранятся записи, форматы, объёмы, требования к контуру.
2. **Пилот 2–4 недели** ([docs/05-poc-plan.md](docs/05-poc-plan.md)): эталонная разметка

   согласованы заранее. Мы не обещаем «волшебный WER» — мы его измеряем и подписываемся цифрами.
3. **Поставка 4–8 недель** (коробка) или 1–2 недели (облако, приватный контур).
