# CLAUDE.md

Все правила работы в этом репозитории — в [AGENTS.md](AGENTS.md); следуй им без
исключений, включая раздел «Жёсткие запреты» (перечень того, что не публикуется, —
там, без пересказа здесь).

Документооборот — в [governance/DOCS.md](governance/DOCS.md): типы документов,
жизненный цикл, куда класть ресёрч и аудит. Карта всех документов с датами —
[governance/DOCS-INDEX.md](governance/DOCS-INDEX.md). Прежде чем создать или
поменять документ, посмотри в индекс: возможно, он уже есть.

Перед любой публикацией запускать:

```bash
python3 tools/check-boundaries.py docs README.md --profile public
python3 tools/site-audit.py
python3 tools/docs-registry.py --check
```

Ненулевой код возврата чекера или реестра — публикация запрещена. Проверяется и этот
файл — он часть публичного контура.
