# CLAUDE.md

Все правила работы в этом репозитории — в [AGENTS.md](AGENTS.md); следуй им без исключений.

Ключевое: это публичный репозиторий продукта Fonotext. Не менять цифры и коммерческие
условия, не публиковать внутреннее (маржа, себестоимость, прайс-гардрейлы), не выводить
`docs/investors/` в навигацию/sitemap. Перед любой публикацией запускать:

```bash
python3 tools/check-boundaries.py docs README.md --profile public
python3 tools/site-audit.py
```

Ненулевой код возврата чекера — публикация запрещена.
