Почему не вручную

Команда, которая слушает звонки руками, физически покрывает единицы процентов записей, а исторический архив не разбирает никогда. Fonotext обрабатывает всё.

Возможности

Спикеры определяются физически по каналам стереозаписи — без нейросетевой диаризации и её ошибок. Таксономия классификации настраивается под ваш бизнес.

Транскрибация со спикерами

Текст каждого звонка с метками «клиент / оператор», таймкодами на уровне слов и пунктуацией.

Классификация звонков

Живой разговор, автоответчик, спам-блокировщик, робот, без ответа; результат разговора и произвольные теги.

Скрипты и стоп-слова

Обязательные фразы приветствия, запрещённые формулировки — автоматически по каждому звонку оператора.

Метрики разговора

Talk ratio, перебивания, паузы, тональность и конфликтность — по звонку, оператору, кампании.

Дашборды и карточка звонка

KPI для руководства, поиск по расшифровкам, карточка с плеером и подсветкой реплик по каналам.

API и вебхуки

Асинхронный REST API: загрузили запись — получили структурированный результат. Идемпотентность, HMAC-подпись.

API за пять минут

Расшифровки доступны всем по API и тарифицируются поминутно. Классификация и теги открываются с подпиской «Аналитика». Полная спецификация — в docs/08-api.md.

# отправили стереозапись звонка
curl -F file=@call.wav -F direction=out \
     -H "Authorization: Bearer $KEY" \
     https://api.fonotext.ru/v1/calls

# → {"call_id":"c7f3e1a2…","status":"queued","charged_sec":282}

# получили результат (вебхук или GET /v1/calls/{id})
{
  "transcript": { "segments": [
    { "start": 0.0, "end": 3.6, "speaker": "operator",
      "text": "Добрый день! Меня зовут Алексей, компания Стройдом." },
    { "start": 0.4, "end": 3.7, "speaker": "client",
      "text": "Да, здравствуйте, удобно, слушаю." } ] },
  "classification": {                    // с подпиской «Аналитика»
    "connection_type": "live_talk", "tags": ["интерес","следующий шаг"] },
  "metrics": { "talk_ratio_client": 0.48, "interruptions": 3 }
}

Формат соответствует выходу нашего открытого демо-стенда — интеграцию можно начинать уже на пилоте.
