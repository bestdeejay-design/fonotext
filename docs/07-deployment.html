07. Поставка и развёртывание

Версия 1.0 от 2026-10-03. Одна кодовая база, три сценария поставки — выбирается заказчиком на пилоте. Во всех сценариях SLA отчётности по новым звонкам ≤ 24 ч (фактически — минуты).

2. Требования к инфраструктуре заказчика (для коробки)

Типовые конфигурации; точный sizing — после пилота по фактическому объёму заказчика (правило: одна карта класса RTX 4090 ≈ 550 ч аудио/сутки, L40S 48 ГБ ≈ 800 ч/сутки).

«Старт» — до ~10 000 часов в месяц

  • 1 сервер: 2× GPU (RTX 4090 24 ГБ или L40S), 32+ ядра, 128 ГБ RAM (ECC желательно),

2× 8 ТБ NVMe, 10 GbE

  • Потребление ~0,8 кВт; размещение 2–4 юнита
  • ОС Linux (Ubuntu 22.04+/Debian), доступ по SSH, docker

«Про» — до ~60 000 часов в месяц

  • 2× GPU-сервера (4× RTX 4090 или 4× L40S каждый), 32–64 ядра, 256 ГБ RAM, 2× 4 ТБ NVMe
  • 1× нода хранения: 64 ядра, 128+ ГБ RAM, 8× 16 ТБ RAID6 (~100 ТБ)
  • Потребление ~3 кВт; ~1/4 стойки; сеть 10/25 GbE

Со стороны заказчика также нужны

  • Доступ к системе записи звонков: REST API / SFTP / S3 (или вебхуки) — уточняется анкетой

из Интеграция и анкета подключения к АТС

  • Внешний сетевой канал: от 100 Мбит/с (типично 1 Гбит/с)
  • Резервное копирование по согласованию (транскрипты ~0,1–0,3 МБ на звонок)

4. Безопасность и соответствие

  • Обработка и хранение только на территории РФ (152-ФЗ); TLS на всех передачах; шифрование

хранилищ опционально.

  • Маскирование номеров телефонов и иных ПДн в транскриптах/выгрузках — по требованию.
  • Ролевая модель (руководство / руководители групп / аналитики / аудит), журнал аудита

доступа и выгрузок.

  • В коробке данные физически не покидают контур заказчика; исходящий трафик — только

обновления ПО (по согласованию, можно офлайн-установкой).

  • Модели и компоненты — только с коммерчески совместимыми лицензиями (см. Модели распознавания и методика оценки качества).

5. Интеграции

  • Вход аудио: REST API / SFTP / S3 / вебхуки (адаптеры), файловые метаданные или API метаданных.
  • Выход: API результатов (транскрипт, теги, метрики), выгрузки XLSX/CSV, рассылка отчётов;

пуш тегов/статусов в CRM заказчика (шаблонные коннекторы — по договорённости).

  • Доступ пользователей: SSO/AD — по требованию (в коробке — без выхода в интернет).

6. Что входит в поддержку (подписка)

  • Мониторинг здоровья пайплайна, реакция на инциденты по SLA (Цены и тарифы: подписки, API и on-prem).
  • Обновления моделей распознавания и классификации 2 раза в год (регресс на эталоне —

качество не падает).

  • Консультации по таксономии и новым отчётам — в рамках часов поддержки.
