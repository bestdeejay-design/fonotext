Карточка оператора

Один оператор: объём, исходы и все 54 пункта чек-листа по этапам — с числами и покрытием.

На какие вопросы отвечает

  • Какие пункты у этого оператора проваливаются чаще всего?
  • Сколько звонков реально оценено по каждому пункту?
  • Где выборки не хватает, чтобы вообще что-то утверждать?

Как читать

  • Начинайте с этапов, где coverage ниже 60 %: там цифра resolved почти ничего не значит.
  • Каждый пункт: Y / N / NA / U; «нет данных» — не «нет».
  • Пункт с N<30 помечен «малое N».

Осторожно

  • Пункты с U>0 — незавершённая оценка; сравнение по resolved без coverage вводит в заблуждение.
  • NA означает «пункт неприменим», а не «выполнен» и не «провален».

Термины раздела

  • Этап чек-листасущностьГруппа пунктов: контакт, выявление потребности, презентация и т. д.
  • Y / N / NA / UстатусДа / нет / неприменимо / нет данных.
  • Resolved, %метрикаДоля выполненных среди пунктов, по которым есть определённый ответ.
  • Coverage, %метрикаКакая доля ожидаемых оценок вообще получена.
  • Малое NметрикаВыборка меньше 30 звонков — сравнение с другими ненадёжно.
  • N звонков на этапеметрикаСколько уникальных звонков дали хотя бы одну оценку на этом этапе.
  • Предложение машинырежимРезультат автопроверки до калибровки: с ним можно работать, но нельзя наказывать.
  • КалибровкарежимСверка машины с оценками людей на одних и тех же звонках.
  • Не оценено (unscored)статусЧек-лист по звонку не рассчитывался — оценки нет вовсе.
