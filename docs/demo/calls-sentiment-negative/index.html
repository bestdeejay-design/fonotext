Звонки

Рабочий список звонков: фильтры, сортировка, переход в карточку. Одна строка — один звонок.

На какие вопросы отвечает

  • Что произошло с конкретным звонком?
  • Какие звонки попали в выборку по фильтрам?
  • Где записи без оператора, без чек-листа, с находками СБ?

Как читать

  • Фильтры складываются по «И»; активные фильтры видны чипами над таблицей.
  • Клик по строке открывает карточку; средняя кнопка мыши — в новой вкладке, не теряя фильтры.
  • «—» означает «данных нет», а не «ноль».

Осторожно

  • Список — не отчёт: порядок по умолчанию «сначала новые», но это день записи, а не точное время, если дата взята из каталога.
  • Идентификатор звонка — технический ключ, а не имя клиента.

Термины раздела

  • call_idсущностьТехнический идентификатор задания/звонка.
  • call_dayсущностьДень звонка в формате ГГГГ-ММ-ДД.
  • Статус заданиястатусГде задание в конвейере: в очереди, в работе, разобрано, мусор, ошибка, на проверке, отложено.
