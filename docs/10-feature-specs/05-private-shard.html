05. Приватный контур на аренде (managed private)

Статусv1.2 (Q3 2027)
Тариф«Приватный контур» 249 900 ₽/мес до 280 000 минут
Зависимости07-deployment.md, 02-architecture.md §6

Проблема

Между «облако» и «коробка on-prem» нет нормального варианта среднего размера.

  • Облако не подходит, когда служба безопасности говорит: «записи разговоров с клиентами

не должны лежать на чужой инфраструктуре» (банки, медицина, коллекшн, госсектор).

  • Коробка требует 2,9 млн ₽ лицензии + железо и ЦОД заказчика, 4–8 недель внедрения и

собственных админов. Для компании со 100–500 операторами это слишком тяжело.

Решение

Выделенный шард на нашей арендованной инфраструктуре. Заказчик получает изоляцию уровня «свой контур» без покупки железа, без лицензионного платежа и без админов:

СвойствоКак реализуется
Изоляция вычисленийотдельный namespace/кластер, отдельные GPU-пулы по расписанию, никакого мультитенантного шаринга процессов
Изоляция данныхотдельный S3-бакет и отдельная БД; ключи шифрования — свои, по запросу — в KMS заказчика (BYOK)
Сетьвозможен приватный канал (VPN/peering) из контура заказчика; публичный API — по желанию
Обновленияокна обновлений согласуются; откат до предыдущей версии модели — по регламенту
МониторингSLA 99,5 %, 24/7, реакция 4 раб. часа (критично — 1 час)
Переездв любой момент можно перейти в коробку: выгружаем дампы и передаём по акту, без потери разметки и версий таксономии

Важно, что остаётся общим: тарифная логика, API, карточка звонка, конструктор таксономии и обновления моделей. Клиент не «застревает» в отдельной ветке продукта.

Как это выглядит

  • Экран «Контур»: статус изоляции, использованные минуты, окно обновлений, ответственный

инженер.

  • Комплаенс-пакет для службы безопасности: схема потоков данных, перечень хранения,

документ «где лежат ПДн», инструкция по уничтожению данных по требованию субъекта ПД.

  • API/вебхуки — те же, что в облаке (08-api.md).

Метрики успеха

МетрикаЦель
Развёртывание нового шарда≤ 5 рабочих дней (для сравнения: коробка — 4–8 недель)
Прохождение проверки ИБ заказчика с первого раза≥ 70 %
Изоляция: результаты теста на кросс-доступ (мы делаем сами и отдаём отчёт)0 инцидентов
Конверсия «Приватного контура» в коробку за 2 года≤ 15 % (значит, не переплачивают)

Этапы

  1. Q3 2027: изоляция на уровне namespace и бакетов, отдельный API-домен, комплаенс-пакет.
  2. Q4 2027: BYOK, приватный канал, окна обновлений по расписанию клиента.
  3. 2028: «приватный контур» для группы компаний (несколько шардов под одним договором).

Монетизация

249 900 ₽/мес — самая высокая подписка, и при этом самая рентабельная: тот же продукт на том же парке, плюс изоляция, которая нам стоит только организационно. Клиент, который иначе ушёл бы в коробку за 2,9 млн ₽ разово, остаётся в recurring — это ключевая защита от каннибализации.

Почему этого нет у других

  • SaaS-сервисы (Rechka, DEERAY, SalesAI) не предлагают изоляцию контура вообще.
  • API-конструкторы дают гибрид, но аналитику заказчик строит сам — изоляции «продукта

целиком» нет.

  • Enterprise-вендоры идут в on-prem: миллионы рублей и месяцы внедрения, без варианта

«подписка с изоляцией».

  • Наша основа — арендованная инфраструктура с автоматизацией: масштаб позволяет выделять

шард без капитальных затрат, а это и есть источник уникального оффера.
