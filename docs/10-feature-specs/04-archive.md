# 04. «Архив под ключ» — конвейер разбора накопленных записей

| | |
|---|---|
| **Статус** | сервис, доступен с Q1 2027 (после MVP облака) |
| **Тариф** | разовая услуга, от 0,38 ₽/мин ([06-pricing.md](../06-pricing.md) §5) |
| **Зависимости** | [02-architecture.md](../02-architecture.md) §4 (режим backfill), [07-deployment.md](../07-deployment.md) |

## Проблема

У типичного контакт-центра накоплен архив в 50–500 тысяч часов, который «никак не доходят
руки разобрать». Вручную это невозможно: 450 000 часов при скорости «1 минута аудио = 5 минут
работы» — это 2,1 млн человеко-часов, то есть 1 300 человек на год. Слушать никто не будет.

Enterprise-вендоры берут такие задачи только внутри большого проекта внедрения: сначала
купите платформу, потом поговорим про архив. SaaS-сервисы за минуты просто не выдерживают
такой объём по цене: 4–5 ₽/мин × 27 млн минут = 110–135 млн ₽.

## Решение

**Производственный конвейер, а не «проект».** Архив обрабатывается отдельным потоком:

1. **Приём.** Физическая отгрузка дисков с записями (для объёмов > 50 тыс. часов это быстрее
   и дешевле сетевой выгрузки) либо канал из анкеты A4 — S3/SFTP/API.
2. **Инвентаризация и дедупликация.** До начала обработки: сверка по `call_id`/хэшу, отчёт
   «принято / дубли / битые файлы». Клиент видит точный объём и не платит за дубли.
3. **Обработка в низком приоритете.** Только прерываемые инстансы (скидка 40–75 %),
   чекпоинт по `call_id` — потеря узла не роняет прогресс. Задача устойчива к прерываниям и
   перезапускам, может идти месяцами.
4. **Приоритет live не страдает.** Воркеры backfill автоматически отдают мощность под новые
   звонки (это уже заложено в [02-architecture.md](../02-architecture.md) §4).
5. **Прогресс и ETA.** Отдельный дашборд: обработано часов, скорость в сутки, прогноз
   завершения, распределение по годам и типам звонков.
6. **Итог проекта.** Аналитический отчёт «что было в архиве»: распределение результатов,
   повторяющиеся проблемы, топ-конфликты, динамика по годам — то, что нельзя было увидеть
   вообще никогда. Дальше — переклассификация под новые вопросы бесплатно в течение 6 месяцев.

**Что это даёт клиенту кроме отчёта.** Архив превращается в работающую базу: теги, метрики,
карточки. Затем он становится основой для дообучения под его специфику — и поводом перейти
на поток ([06-pricing.md](../06-pricing.md) §2).

## Экономика конвейера

| Параметр | Значение |
|---|---|
| Цена для клиента | 0,38–0,55 ₽/мин (пакеты — [06-pricing.md](../06-pricing.md) §5) |
| Себестоимость обработки | только прерываемые инстансы, низкий приоритет + LLM-слой |
| Пропускная способность | ≈9 тыс. часов аудио в сутки на 8 карт 4090-класса, работающих круглосуточно |
| Пример сделки | 450 тыс. часов ≈ 7,8 млн ₽, срок 6–12 недель |

Пример расчёта: 450 000 часов = 27 млн минут × 0,48 ₽ = **12,96 млн ₽** выручки проекта;
обработка на 8 картах — около 50 суток чистого времени с учётом прерываний и повторов.

## Метрики успеха

| Метрика | Цель |
|---|---|
| Соблюдение ETA | ≥ 90 % проектов в срок (или раньше) |
| Доля брака и дублей в инвентаризации | ≤ 2 % |
| Конверсия архива в подписку на поток | ≥ 40 % проектов |
| Отзыв/повторный проект по рекомендации | ≥ 1 кейс на 2 проекта |

## Этапы

1. **Q1 2027:** конвейер, инвентаризация, дашборд прогресса; пилот на архиве 60 тыс. часов.
2. **Q3 2027:** физическая отгрузка дисков, мультиархивность (несколько источников у одного
   клиента), шаблон итогового отчёта.
3. **2028:** self-service расчёт стоимости архива, типовые отчёты по отраслям.

## Монетизация

Разовая выручка 2–15 млн ₽ за проект, из которой 90 % приходится на сервис и аналитику, а не
на вычисления. Стратегическая роль выше, чем деньги: архив — самый короткий путь внутрь
заказчика, потому что он (а) не конкурирует с текущими бюджетами на ОКК, (б) даёт результат,
который невозможно не заметить, (в) естественно ведёт к подписке.

## Почему этого нет у других

- **SaaS за минуты** (Rechka, DEERAY, SalesAI): разбор 27 млн минут по 4–5 ₽/мин — это
  110–135 млн ₽, бюджет неподъёмный.
- **API-конструкторы** (SpeechSense): технически могут, но деклассификация/аналитика и
  производственный процесс — на клиенте.
- **Enterprise-вендоры:** делают, но только как часть проекта внедрения стоимостью в
  миллионы, с внедрением в месяцы.
- **Наше преимущество** — экономика аренды: прерываемые инстансы + низкий приоритет + LLM
  для классификации делают цену 0,38–0,55 ₽/мин возможной при здоровой марже.
